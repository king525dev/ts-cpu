Reference

This is a lookup document. It assumes you already know what you want.

1. Quick facts
Architecture        8-bit stack machine
Value range         0 – 255
Stack               256 bytes, LIFO
RAM                 256 bytes
Program             up to 256 bytes
Instructions        40
Instruction size    1 or 2 bytes
Endianness          n/a (no multi-byte values)
Registers           PC and SP, both internal
Flags register      none (comparisons push a value)
2. Memory map
0x00  ┌────────────────────────┐
      │  RAM slot 0 (wildcard) │
0x01  ├────────────────────────┤
      │  Variables             │
      │  (VAR / @name)         │
      │                        │
0xFF  └────────────────────────┘

The stack is not memory-mapped. It lives inside the CPU as a separate 256-byte array.

Program memory is also separate. The CPU reads bytecode from its own program array, indexed by the program counter.

Address 0 in RAM is special: STA 0 stores into the next free slot, and LDR 0 reads back the value most recently stored that way.

4. OXNTAL syntax

Numbers

FormExampleValue
Decimal1010
Hex0x0A10
Binary0b101010

The 0x and 0b prefixes are required. Values are truncated to 8 bits when emitted. LDA 300 pushes 44.

Comments

Delimited by two // markers. Everything between the first and the second is discarded.

// this is a comment //
LDA 5

An odd number of // markers is an error.

Labels

>loop
JMP loop

>name declares a label at the current bytecode position. name alone references it.

Variables

VAR counter
@counter        ; equivalent
STA counter
LDR counter

Both forms allocate the next free RAM address. Address allocation starts at 1, since 0 is reserved by STA/LDR.

7. What OXN does not have

Documented explicitly so you know what not to look for.

No registers            No user-visible GPRs. Everything is on the stack or in RAM.

No flags register       Comparisons push a value, they don't set flags. To branch, use JCN.

No addressing modes     Only immediate (LDA) and absolute (STA, LDR, JMP, JCN).

No functions            No CALL, no RET. Subroutines are by convention.

No interrupts           The CPU runs from load to BRK.

No floating point       Integers only, unsigned, 0–255.

No signed integers     SUB and NEG wrap. There is no notion of negative in the ISA.

No assembler directives No .org, .db, .equ, no sections.

No expressions         Parameters are single numbers, labels, or variables.

No macros              Beyond the four shorthands.

No linker             A program is one file.
